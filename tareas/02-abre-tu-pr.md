# 🚀 Tarea 2 · Abre tu propio pull request

⏱️ **Tiempo:** unos 20 minutos. **Qué practicas:** el flujo completo, de fork a pull request.

## 👣 Pasos

1. 🍴 **Haz un fork.** En este repositorio, pulsa **Fork** (arriba a la derecha) y crea la copia en tu cuenta.
2. 📥 **Clónalo** en tu computador o en tu Codespace, con la dirección de *tu* fork:

   ```bash
   git clone https://github.com/TU-USUARIO/prueba_estudia_c2_basico.git
   cd prueba_estudia_c2_basico
   ```

3. 🌿 **Crea una rama** con tu usuario:

   ```bash
   git switch -c presentacion-TU-USUARIO
   ```

4. 📄 **Crea tu archivo** `estudiantes/TU-USUARIO.md`. Copia como modelo [estudiantes/ejemplo.md](../estudiantes/ejemplo.md) y complétalo con tus palabras.
5. 💾 **Guarda el cambio y súbelo:**

   ```bash
   git add estudiantes/TU-USUARIO.md
   git commit -m "Agrega la presentación de TU-USUARIO"
   git push -u origin presentacion-TU-USUARIO
   ```

6. 📬 **Abre el PR.** Entra a tu fork en GitHub: aparece un aviso amarillo con **Compare & pull request**. Verifica que el destino sea `JuanFeDS/prueba_estudia_c2_basico`, rama `main`.
7. ✅ **Llena la plantilla** del PR y márcala. Pulsa **Create pull request**.

## 🛟 Si git te da problemas

Puedes hacer lo mismo desde el navegador: en tu fork, pulsa **Add file → Create new file**, escribe `estudiantes/TU-USUARIO.md`, y al guardar elige **Create a new branch**.

## 📮 Entrega

Pega en el chat el enlace de **tu PR**.
